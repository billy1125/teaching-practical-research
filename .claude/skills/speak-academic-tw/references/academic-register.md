# 中文學術語域：五類問題與改法

中文論文讀起來不順，多半不是字詞用錯，是句子扛太多東西。這份檔案把常見問題分成五類，每類給識別信號與 before/after。編號（AR-1 到 AR-22）供逐句修訂時引用。

## 一、語法與句式

### AR-1 句子過長

**識別信號**：一個句號之間超過 60 字；讀到一半要回頭找主詞。

中文沒有英文的關係子句，長句只能靠逗號串，串到第四個逗號讀者就掉線了。

- 原句：本研究透過蒐集 2020 年至 2023 年間北部三所大學共 428 位大學生的問卷資料，並在控制性別、年級與家庭社經地位等變項後，以階層迴歸分析檢驗學業自我效能感在學習投入與學業成就之間所扮演的中介角色。
- 修訂：本研究蒐集 2020 年至 2023 年北部三所大學 428 位大學生的問卷資料。控制性別、年級與家庭社經地位後，以階層迴歸分析檢驗學業自我效能感在學習投入與學業成就之間的中介角色。

拆句原則：一句講一件事。方法段落尤其適合拆，因為步驟本來就是分開的。

### AR-2 多層修飾疊加

**識別信號**：一個名詞前面掛了三層以上的「的」。

- 原句：影響學生在數位學習環境中的學習成效的關鍵的個人因素
- 修訂：在數位學習環境中，影響學生學習成效的關鍵個人因素

處理方式：把修飾語拆到句子前面當狀語，或改成短句。

### AR-3 主語漂移

**識別信號**：句子前半的主詞跟後半不同，中間沒有交代。

- 原句：在分析實驗資料後，結果顯示三組之間並無顯著差異，因此推翻了原本的假設。
- 修訂：分析實驗資料後，三組之間並無顯著差異，此結果不支持研究假設一。

「推翻」的主詞是誰？原句沒交代。修訂版把主詞明確化，同時把「推翻」降回原文實際支持的強度（見 AR-9）。

### AR-4 缺主詞

**識別信號**：一整段沒有出現主詞，讀者要自己猜是研究者、受試者還是模型。

- 原句：先進行前測，接著給予為期八週的介入，最後進行後測。
- 修訂：受試者先完成前測，接受為期八週的介入後，再完成後測。

方法段落是重災區。中文可以省略主詞，但學術寫作省略會造成歧義時，補回來。

### AR-5 被動濫用

**識別信號**：「被」出現在不需要強調受事者的句子。

- 原句：實驗數據被研究者以 SPSS 26.0 被進行了統計分析。
- 修訂：研究者以 SPSS 26.0 分析實驗數據。

中文的被動語態帶有「遭受」的語感，不像英文的 passive voice 那樣中性。翻譯腔的論文最容易犯。真正需要強調受事者、或施事者不重要時才用被動。

### AR-6 標點錯誤

**識別信號**：整段只有逗號沒有句號；分號用來連接不對等的成分；頓號用在句子之間。

- 原句：本研究有三個目的，一是檢驗量表的信效度，二是比較不同年級的差異，三是探討中介效果，研究對象為國中生。
- 修訂：本研究有三個目的：一是檢驗量表的信效度，二是比較不同年級的差異，三是探討中介效果。研究對象為國中生。

冒號帶出並列項目，句號區隔不同的意思單位。標點細節見 [taiwan-localization.md](taiwan-localization.md)。

## 二、學術語域

### AR-7 口語詞

**識別信號**：出現日常對話會用、但論文不會用的詞。

| 口語 | 學術表達 |
| :-- | :-- |
| 很多、超多 | 大量、多數、為數不少 |
| 非常好、超級明顯 | 顯著、明顯（配數據） |
| 差不多、大概 | 近似、約、大致 |
| 搞清楚、弄懂 | 釐清、確認 |
| 一堆問題 | 多項問題、若干問題 |
| 蠻高的 | 偏高 |
| 沒什麼用 | 效果有限、未達顯著 |
| 講白了 | 換句話說、具體而言 |

注意：「大概」改「約」是語域問題；但「大概」表示不確定的判斷時，改成「傾向」而不是刪掉（見 AR-9）。

### AR-8 情緒性形容詞

**識別信號**：形容詞在描述研究者的感受，不是描述現象。

- 原句：令人驚訝的是，實驗組的表現遠遠超越對照組，這個結果相當振奮人心。
- 修訂：實驗組的表現顯著高於對照組（*t* = 4.21, *p* < .001）。

「令人驚訝」「振奮人心」「可惜」「遺憾」在討論段可以極少量使用，前提是對應到具體的預期落差；純粹表達情緒的一律刪。

### AR-9 推論強度不當

**識別信號**：動詞的強度與證據不符。這是學術寫作最要命的語言問題。

強度由弱到強：**可能／或許 < 傾向、大致 < 顯示、指出 < 支持 < 證實、證明**

- 原句：本研究證明了社會支持能有效降低憂鬱症狀。
- 修訂：本研究結果支持社會支持與憂鬱症狀之間的負向關聯。

**這一類只能降不能升，而且只在原文明顯過強時降。** 作者寫「傾向支持」是刻意的謹慎，不是語言問題，不准改成「顯示」。橫斷研究不寫「導致」，相關分析不寫「影響」——但這條的判斷依據是原文自己說的研究設計，不是你對研究方法的評價。

### AR-10 人稱不一致

**識別信號**：同一篇裡「本研究」「筆者」「我們」「作者」混用。

- 原句：本研究採用質性訪談法。筆者共訪談 12 位教師。我們發現三個主題。
- 修訂：本研究採用質性訪談法，共訪談 12 位教師，並歸納出三個主題。

台灣論文的慣例：單一作者用「本研究」或「筆者」，多位作者用「本研究」或「研究者」，理工科常見全篇用「本研究」。統一成作者原本用得最多的那一個，不要自作主張換一套。學位論文有校方格式規範時以規範為準。

### AR-11 中英夾雜不當

**識別信號**：有標準中譯的術語卻寫英文；或首次出現的英文縮寫沒有全稱。

- 原句：我們用 CNN 做 feature extraction，然後把 output 丟進 classifier。
- 修訂：本研究以卷積神經網路（convolutional neural network, CNN）擷取特徵，再將輸出送入分類器。

規則：首次出現寫「中譯（英文全稱, 縮寫）」，之後統一用縮寫或中譯，全篇一致。沒有公認中譯的術語保留英文，不要自創譯名。

## 三、清晰度

### AR-12 指代不明

**識別信號**：「這」「其」「該」「此」前面有兩個以上可能的指涉對象。

- 原句：實驗組接受認知訓練，對照組接受一般課程，這對後測分數有顯著影響。
- 修訂：實驗組接受認知訓練，對照組接受一般課程。組別對後測分數有顯著影響。

處理方式：把「這」換成具體名詞。判斷不出指涉對象時不要猜，列進「需作者確認事項」。

### AR-13 範圍詞模糊

**識別信號**：「相關研究」「某些情況」「部分學者」「許多因素」而沒有下文。

- 原句：相關研究指出，在某些情況下這個方法效果有限。
- 修訂：Chen 與 Lin（2021）指出，在樣本數低於 100 時此方法的檢定力不足。

作者有引用就補進去；沒有就標「〔需補引用〕」並在需作者確認事項列出，不代查也不編。

### AR-14 語意歧義

**識別信號**：一句話有兩種讀法。

- 原句：本研究分析了教師與學生的互動模式與學習成效的關聯。
- 兩種讀法：(A)「教師與學生的互動模式」跟「學習成效」的關聯；(B)「教師」跟「學生的互動模式與學習成效」的關聯。

修訂版採一種讀法（通常是上下文比較合理的那個），但一定要在需作者確認事項寫明：「原句可作 A 或 B 兩種解讀，修訂版採 A，請確認。」**不要靜默地替作者選一種。**

### AR-15 邏輯連接詞錯用

**識別信號**：「因此」「然而」「此外」跟前後句的實際邏輯關係對不上。

- 原句：實驗組分數較高，然而對照組的變異數也較大。
- 修訂：實驗組分數較高，對照組的變異數則較大。

原句的兩件事不是轉折關係，是並列。連接詞用錯會誤導讀者對論證結構的理解。

## 四、精簡度

### AR-16 名詞化贅句

**識別信號**：「進行／做出／給予／實施 ＋ 動詞名詞」。這是中文論文最普遍的贅句形式。

| 冗長 | 精簡 |
| :-- | :-- |
| 進行了分析 | 分析了 |
| 對⋯⋯做出了討論 | 討論了 |
| 給予⋯⋯評估 | 評估 |
| 實施了測量的動作 | 測量 |
| 進行資料的蒐集工作 | 蒐集資料 |
| 具有顯著性的差異 | 差異顯著 |
| 有著明顯的提升 | 明顯提升 |

例外：「進行實驗」「進行訪談」這類已經是固定用法的不必改。

### AR-17 冗詞

**識別信號**：拿掉之後意思完全不變的詞。

| 冗詞 | 處理 |
| :-- | :-- |
| ⋯⋯的部分、⋯⋯的方面、⋯⋯的動作 | 直接刪 |
| 基本上、事實上、實際上（無對比對象時） | 直接刪 |
| 所謂的 | 直接刪（除非真的在定義術語） |
| 相關的（「相關的研究」「相關的因素」） | 直接刪 |
| 一個、一種、某一個（可省略的量詞） | 多半可刪 |
| 加以（「加以分析」） | 改成「分析」 |

- 原句：在資料處理的部分，基本上我們會先對缺失值加以處理。
- 修訂：資料處理先從缺失值開始。

### AR-18 同義重複

**識別信號**：兩個詞意思一樣，疊在一起。

- 「大約近似於」→「約為」
- 「主要的核心概念」→「核心概念」
- 「事先預先設定」→「預先設定」
- 「共同一起合作」→「合作」
- 「未來的展望」→「展望」或「未來方向」

### AR-19 廢話句

**識別信號**：整句拿掉，資訊不損失。

- 「本節將說明本研究的研究方法。」（後面就是方法，不必預告）
- 「由上述可知，這是一個值得探討的議題。」（沒有新資訊）
- 「以下針對每個變項逐一進行說明。」（直接說明即可）
- 「這個問題是相當複雜的，涉及許多層面。」（沒有指出是哪些層面）

摘要與會議摘要有字數限制，這類句子一律刪。長篇的緒論與討論可以保留少量承接句，但不要每節開頭都來一句。

## 五、連貫性

### AR-20 段落沒有主題句

**識別信號**：一段話讀完才知道重點是什麼；或整段都是細節，沒有判斷。

學術段落的標準結構：主題句 → 證據／論證 → 小結（可省略）。

- 原句（段首）：Smith（2019）以 200 位受試者進行實驗。Lee（2020）則用了質性方法。Wang（2021）的樣本是大學生。
- 修訂（段首補主題句）：既有研究在方法與樣本上分歧明顯。Smith（2019）以 200 位受試者進行量化實驗，Lee（2020）採質性方法，Wang（2021）則限於大學生樣本。

補主題句的前提是**這個判斷原文本來就有**（可能藏在段尾）。原文完全沒有判斷時，標「（需作者補充：這段想說明什麼？）」，不代寫。

### AR-21 句間邏輯斷裂

**識別信號**：前後句都通順，但接不起來，讀者要自己補中間那一步。

- 原句：本研究採用滾雪球抽樣。最終樣本共 87 位。
- 修訂：本研究採用滾雪球抽樣，由初始的 12 位受訪者輾轉推介，最終取得 87 位樣本。

補的是原文其他地方已經有的資訊。找不到就保留原樣，不要編一個銜接。

### AR-22 時間標記詞不一致

**識別信號**：同一段裡研究行為的時態標記混用。

- 原句：本研究將採用問卷調查法，共回收 320 份有效問卷，未來將以迴歸分析檢驗假設。
- 修訂：本研究採用問卷調查法，共回收 320 份有效問卷，並以迴歸分析檢驗假設。

已完成的研究用完成式的標記（「已」「共」或不加標記），研究計畫書用未來式的標記（「將」「預計」），全篇一致。論文寫作最常見的錯誤是計畫書改成論文時忘了把「將」拿掉。

## 改法的順序

同一句同時中好幾類時，照這個順序處理，避免改到一半互相打架：

1. 先斷句（AR-1）——句子拆開之後，其他問題才看得清楚
2. 補主詞與指代（AR-3、AR-4、AR-12）
3. 刪冗詞與名詞化（AR-16、AR-17、AR-18）
4. 調語域（AR-7、AR-8）
5. 最後檢查推論強度（AR-9）——這一步是把關，不是修飾

第 5 步一定放最後，因為前面的改寫最容易在無意間把強度改掉。
