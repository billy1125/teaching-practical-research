# 保護清單與誤殺防護

潤稿最大的風險不是改不乾淨，是把研究內容一起改掉。一個小數位漂掉、一個「傾向」變成「證實」，論文就從嚴謹變成造假。動筆前先把這些內容圈起來，修訂全程原封不動；改完回頭逐項核對。

## 七類保護對象

### 1. 數據與統計值

所有數值、單位、小數位數、統計符號與其報告格式。

- 「*M* = 4.32, *SD* = 0.87, *t*(126) = 4.21, *p* < .001, *d* = 0.75」逐字保留，包含斜體、小數點前的零省略慣例（`.001` 不是 `0.001`，APA 格式對機率值的規定）
- 數值的精確度不得漂移：「42.7%」不能變成「約四成」，「約 30 分鐘」也不能變成「30 分鐘」
- 樣本數的 *N*（全體）與 *n*（分組）大小寫不能互換
- 「未達顯著」不能改成「無差異」「沒有影響」——統計上這是兩件事
- **絕不為了讓句子更具體而補上原文沒有的數值**

### 2. 引用與參考文獻

- 作者姓名的拼寫、順序、et al. 的用法照原文
- 年份、頁碼、卷期號一字不動
- `\cite{}`、`\citep{}`、`\citet{}` 的 key 與指令型態不動
- 參考文獻清單整條不動，包含標點與縮排（格式是否符合期刊規範由作者自行核對）
- 中文引用的「（陳大明，2021）」全形括號與逗號照原文格式，不套用一般標點規則

### 3. 專有名詞與術語

- 學術術語同一篇全篇一致，**不因為「換句話說」而被同義替換**：第二次出現「工作記憶」還是「工作記憶」，不會變成「短期記憶系統」
- 機構名、儀器名、軟體名與版本（SPSS 26.0、R 4.3.1、MATLAB R2023a）照原文
- 量表與測驗名稱、其中文譯名照作者用法
- 資料集、模型、演算法的名稱照原文，不翻譯也不改大小寫（BERT 不寫成 Bert）
- 作者自創的術語或代號照用，只在全篇不一致時提醒

### 4. 公式、變數符號、單位

- 數學環境整塊不動：`$...$`、`\begin{equation}`、`align`、`gather`
- 行文中的變數符號、下標、上標照原文（*x*ᵢ 不改成 *X*ᵢ）
- 單位與其寫法（μm、°C、mg/L、rpm）照原文，不換成中文
- 化學式、基因名稱、物種學名的斜體與大小寫照原文

### 5. 圖表編號與交叉引用

- 「圖 3」「表 2」「附錄 A」的編號不動
- `\ref{}`、`\label{}`、`\autoref{}` 不動
- 「如第 2.3 節所述」的章節編號不動
- 圖表標題（caption）**可以改語言**，但編號、單位、統計註記（「\*\*p < .01」）不動

### 6. 引號內的原文引述與受訪者原話

質性研究的訪談逐字稿、直接引述的文獻原文。

- 引號內一字不改，包括裡面的口語、贅詞、中國用語、不通順的句子——引述的價值就是原汁原味
- 受訪者代號（P03、教師 A）與其對應關係不動
- 原話有明顯錯字時標註提醒作者，不代改

### 7. 研究倫理與利益揭露聲明

- IRB／研究倫理審查編號、核准日期
- 受試者同意程序的描述
- 經費來源、計畫編號、贊助單位
- 利益衝突聲明、資料可得性聲明、作者貢獻聲明
- 這幾類的制式語言是法律與規範需求，不是罐頭腔，只能調前後銜接，不能調意思

## 容易誤殺的情況

規則對了，判斷錯了，一樣改壞。這些情況先放行：

| 看起來像 | 其實是 | 判斷方法 |
| :-- | :-- | :-- |
| 方法段落重複囉唆 | 為了可重製性刻意寫全 | 刪掉之後別人還做得出來嗎？做不出來就不刪 |
| 過度謹慎的「可能」「傾向」 | 作者對證據強度的正確判斷 | 這一類只能降不能升，看起來太弱也不動 |
| 冗長的統計敘述 | 期刊規範要求的完整報告 | 統計值一律不動，只能動連接的文字 |
| 「本研究」重複出現 | 學術寫作的正常密度 | 一段出現三、四次是常態，不必為了變化而換詞 |
| 名詞化「進行實驗」 | 已固定的學術用語 | 「進行實驗」「進行訪談」是慣用，不必改 |
| 被動語態 | 施事者不重要或刻意隱去 | 質性研究的匿名處理常需要被動，放行 |
| 結果段的解釋句 | 期刊要求的 Results and Discussion 合併寫法 | 章節標題若已合併，放行 |
| 中英夾雜 | 沒有公認中譯的術語 | 想不出標準中譯就保留英文，不自創譯名 |
| 空泛的「重要」 | 掛著具體的比較基準 | 後面接得出「比什麼重要、差多少」就放行 |
| 「顯著」二字 | 統計術語，不是程度副詞 | 配著 *p* 值出現時是術語，絕對不改 |
| 排比三段式 | 三個平行的研究假設 | 假設本來就該平行，不改 |
| 引號內的中國用語 | 直接引述的原文 | 引號內一律不動 |

拿不準的通用判斷法：**這句話改掉之後，另一位研究者少知道了什麼？** 少知道了任何事實、數值、步驟或作者的判斷強度，就不能改；什麼都沒少，才是可以動的文字。

再一條：**看不出這是語言問題還是研究問題時，當成研究問題，不動。**

## 回讀核對程序

修訂完成後，依序執行：

1. 把修訂前圈出的保護對象列成清單（數據 N 項、引用 N 項、術語 N 項、公式 N 項、圖表編號 N 項、引述 N 項、聲明 N 項）
2. 在修訂版逐項搜尋確認存在且逐字一致
3. 確認沒有新增原文沒有的數據、來源、方法細節
4. **強度核對**：把原文與修訂版的推論動詞列出來對照（可能／傾向／顯示／支持／證實），一個都不能升級
5. 確認術語在修訂版全篇仍然一致，且與作者原本的用法一致
6. LaTeX 稿另外確認：數學環境、`\cite`、`\ref`、`\label`、自訂巨集完全沒被動到
7. 任何一項失敗：回去修正，不交稿
