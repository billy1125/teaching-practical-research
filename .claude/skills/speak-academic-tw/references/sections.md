# 文體 × 章節：修飾力度與禁改項

同一句話在方法段落要輕輕動，在摘要可以整句重寫。這份檔案給每個章節的力度基準、常見問題、禁改項。

## 力度的意思

| 力度 | 可以動到什麼 |
| :-- | :-- |
| 輕 | 只改句內：斷句、刪冗詞、改標點、修語法。不動句子順序，不合併句子，不刪句 |
| 中 | 可以合併句子、調整句序、刪除完全無資訊的句子。段落結構不動 |
| 重 | 可以重組段落、大幅刪減、重寫句子。前提是每個資訊點都保留 |

任何力度都不得改動保護清單七類內容，見 [protected-list.md](protected-list.md)。

## 期刊論文與學位論文

### 摘要（力度：重）

摘要有字數限制，資訊密度優先。

常見問題：

- 開頭一句廢話（「本研究旨在探討⋯⋯」其實可以直接寫研究問題）
- 方法寫得太細（摘要不需要寫器材型號與軟體版本）
- 結果只寫「有顯著差異」而不寫方向與大小
- 結論膨脹成「具有重要的理論與實務意義」

改法：確認摘要包含目的、方法、結果、結論四個要素。缺哪一項就標「（需作者補充：⋯⋯）」，不代寫。有字數限制時，先砍廢話句與方法細節，再壓句子。

**禁改**：關鍵字、統計數值、樣本數。中英文摘要並存時，只改指定的那一份，不要順手動另一份，也不要要求兩份逐句對齊——那是作者的翻譯決定。

### 緒論（力度：中）

常見問題：

- 公式化開場：「在當今全球化的時代」「隨著科技的快速發展」（見 [ai-traces.md](ai-traces.md) AI-1）
- 研究背景寫成教科書，鋪了三段還沒進入研究問題
- 研究缺口用「相關研究較少」帶過，沒有指出缺什麼

改法：第一句就該有這篇論文特有的資訊。時代大帽子直接刪，刪掉不用補。

**禁改**：研究缺口的論證結構。作者鋪陳「A 有人做、B 有人做、A 與 B 的交集沒人做」時，這三步一步都不能省，即使讀起來重複。研究問題與假設的表述一字不動（那是作者對研究範圍的界定，不是文筆）。

### 文獻回顧（力度：中）

常見問題：

- 變成文獻清單：「Smith 說⋯⋯。Lee 說⋯⋯。Wang 說⋯⋯。」沒有整合
- 引用歸屬模糊：「有學者認為」「相關研究指出」（見 AR-13）
- 段落沒有主題句（見 AR-20）

改法：補主題句、補句間邏輯連接。整合的判斷若原文有（常藏在段尾），移到段首；原文沒有就標註請作者補。

**禁改**：作者對每篇文獻的詮釋。作者說 Smith（2019）「支持」某觀點，你不能因為覺得應該是「部分支持」就改。引用格式、年份、作者姓名一字不動。

### 方法（力度：輕）

常見問題：

- 缺主詞，不知道是研究者做還是受試者做（見 AR-4）
- 步驟寫成一大段，沒有順序標記
- 被動語態濫用（見 AR-5）

改法：斷句、補主詞、把步驟順序講清楚。

**禁改**（這一段最嚴格）：

- 步驟的先後順序，一步都不能調
- 參數、劑量、時間、溫度、版本號、器材型號
- 統計方法的名稱與設定
- 抽樣方式、納入與排除條件
- 倫理程序與 IRB 編號

方法段落的敘述如果讀起來重複，多半是為了可重製性刻意寫的，不要精簡掉。看到方法上疑似有問題（例如兩處參數不一致），寫進「需作者確認事項」，不做判斷、不改。

### 結果（力度：輕）

常見問題：

- 數值與文字敘述重複到冗長（「表 3 顯示，A 組平均為 4.32，B 組平均為 3.87，A 組高於 B 組」）
- 結果段落夾雜解釋（那是討論段的事，但**不要替作者搬家**，最多提醒）
- 統計報告格式不一致

改法：只改句構與贅詞。數值敘述與圖表重複時，可以建議精簡文字敘述，但要在說明欄寫清楚刪掉的數值在表幾可以查到。

**禁改**：

- 所有數值、小數位數、單位、正負號
- 統計符號與其斜體／大小寫慣例（*p*、*t*、*F*、*M*、*SD*、*N* 與 *n* 的區別）
- 顯著與不顯著的表述，包含「未達顯著」不能改成「無差異」
- 圖表編號與交叉引用

### 討論（力度：中）

常見問題：

- 推論強度膨脹（見 AR-9），這是討論段最常見也最嚴重的語言問題
- 把相關講成因果
- 與文獻對話寫成「這與 Smith（2019）的結果一致」就結束，沒說哪裡一致
- 研究限制寫成套話（「樣本數較少，未來可擴大樣本」）

改法：把過強的動詞降回原文證據支持的層級。作者本來就寫得謹慎的不要動。

**禁改**：

- 作者的詮釋方向。作者把某個結果解釋成 X 機制，你不能改成 Y
- 已經夠謹慎的表述，「可能」「傾向」不准升級
- 研究限制的內容，只能改文字不能刪項目

### 結論（力度：中）

常見問題：

- 空洞收尾：「總的來說」「綜上所述」「本研究具有重要的理論與實務意義」
- 結論超出結果支持的範圍
- 未來研究方向寫成罐頭

改法：砍空洞收尾，允許段落停在最後一個具體句子上。結論的每一句都要對應到結果段落的某個發現，對應不到的標註請作者確認。

**禁改**：研究限制不刪，即使讀起來像在扣自己分數。實務建議的具體內容不動。

## 研究計畫書

力度：中。包含國科會計畫、研究申請書、學位論文計畫書、IRB 文件。

常見問題：

- 時間標記詞混用（見 AR-22），「將」「已」「預計」跳來跳去
- 可行性寫得太保守，讀起來像沒把握
- 預期成果寫成空話（「提升學術能量」「促進產學合作」）

改法：統一時間標記為未來式（「將」「預計」）。預期成果要對應到具體可查核的產出，作者沒寫就標註請他補。

**禁改**（這是評審會看的東西）：

- 可行性與時程的表述不能改弱。作者寫「已完成前導研究」不能改成「已進行部分前導研究」
- 經費項目、金額、人力配置
- 研究團隊成員的職稱與分工描述
- IRB 相關的程序描述
- 計畫書格式規範要求的固定用語與段落標題

計畫書有字數或頁數限制時，先問清楚上限再決定精簡幅度。

## 會議摘要與海報

力度：中偏重。字數壓縮優先。

常見問題：

- 塞不進字數限制，作者用刪標點、砍空格的方式硬塞
- 為了短而犧牲關鍵資訊（樣本數、統計值不見了）
- 海報文字直接複製論文段落，句子太長

改法：先砍廢話句與修飾語，再壓句構，最後才考慮合併資訊點。優先保留的順序：研究問題 > 結果數值 > 方法 > 背景。

海報文字另外考慮：句子控制在 40 字以內，一個資訊區塊講一件事，條列可以比論文多。

**禁改**：投稿系統要求的固定欄位標題（Background／Methods／Results／Conclusions 或中文對應）、關鍵字、作者與單位資訊、字數上限本身。

## 跨章節的共通檢查

一次處理多個段落時，額外核對這些：

1. **術語全篇一致**：同一個概念，摘要、方法、結果用的是不是同一個詞
2. **縮寫首次出現有全稱**，之後不再重複全稱
3. **人稱一致**（見 AR-10）
4. **時間標記一致**（見 AR-22）
5. **數值在不同章節間一致**：摘要寫的樣本數與方法段一致嗎？不一致時列進需作者確認事項，不自行決定何者為準
6. **交叉引用有效**：提到「第 3.2 節」「表 4」時，那個編號在文中真的存在嗎

只拿到節錄時，這些跨章節檢查做不了，在輸出時提醒作者全文自查。
